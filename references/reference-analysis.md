# 参考拆解与灰模自查

## 开始记录

形成一份短的项目记录：目标版本/格式、源工程、交付位置、风格、不可改变项、关键特征、相机/参考帧、组件预算、动画路径。它是制作记录，不是必须先让用户填写的表单。

从 GIF/视频分离相机转动和模型运动。选择暴露不同侧面、最大/最小姿态、遮挡变化与循环接缝的帧；记录方向、周期、相位和联动关系。只能看到一面的图不能证明背面拓扑；推断要标明，不声称提取原作者模型。

将特征按贡献拆开：

- **剪影**：头身柄比例、三尖护手、叉角、弧形开口、刃尖落点。
- **体积**：薄刃收口、金框/白衬/凹槽层级、宝石镶口、柄的厚度。
- **表面**：符文是黑纹还是紫纹、纹路拐弯、接头连续性、材质分区。
- **运动**：部件共同抖动、链齿方向、眼睛相位、环绕前后关系、特效出口。
- **光效**：实心亮核心、硬边轮廓、透明风尾、是否确有 bloom；分开判断。

## 制作顺序

先做主要比例的少组件灰模。用正交前后侧面检查厚度、接缝、负空间，用斜视验证镶嵌。俯视圆度需要正交相机，不能拿透视椭圆认定几何不圆。灰模缺失的结构不靠贴图亮暗掩盖。

先做一个完整局部（例如一个晶体与一层壳、一段薄刃与金框），确认 UV、导出和成本后再复制。重复部件是否必须独立取决于形状/运动，不取决于截图中有几条亮线。

先固定主色、中间色、暗色与强调色，再绘细节。默认可采用用户历史偏好的明亮精细像素武器，但用户要求原版简洁或高保真时按该任务执行。不要将“所有材质 32px”“只有 50 个组件”作为任何模型的强制尺寸。

修正时给参考局部与当前模型相同的部件编号，只改本轮差异。多轮修正后重新对照整体比例和主色，防止修细节时逐步偏离原图。
