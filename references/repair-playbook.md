# 修正手册

顺序：保存现场 → 固定视图/时间 → 单独隐藏问题组或换诊断材质 → 确认原因 → 最小修改 → 同条件复查 → 导出重查。不要在定位之前批量加壳或改变所有颜色。

|现象|如何区分原因|修正与回归|
|---|---|---|
|刃口/接头断开|看共享端点、旋转后的世界坐标和侧视封口|修几何连接，不用前景纹理遮洞；保留参考中有意的收尖空白|
|宝石悬浮/穿模|检查核心背面、镶口、框架深度|调整镶嵌深度与框架净空；旋转视图确认真实体积|
|颜色闪烁或穿插|分别隐藏内层、外层、壳和透明特效|共面删冗余或分离；透明排序单独排查，不反复堆表面|
|黑紫方块|看贴图引用、丢图、UV 边界、当前 PNG 与内嵌图是否一致|先修引用/UV；若是误画，查看撤销历史，不把错误色块当设计重绘|
|改一个色板导致多处变色|确认 UV 复用和活动材质；检查 Paint 模式误涂|恢复本次误操作，必要时拆分材质角色；保留用户有意编辑|
|描边成实心盒|核对负尺寸、面绕序、front/double、主体是否透明|保留正确单面剔除，检查主体遮挡；别用 double 修复壳|
|描边 X 交叉|隐藏各段壳，检查凹口内侧、连接端面和相邻穿插|沿组合轮廓布边界；删除确定无用的端/侧面，正背和斜视复查|
|渐变倒向|检查反转后的面语义和旋转面的世界方向|重映射 UV，不能只翻整张 PNG|
|运动移走或越播越偏|对照模型、父节点、世界和 Display 坐标；查累加变换|每帧从基线计算；实际父变换下测循环和恢复|
|Edit 会动 Display 不动|查看驱动的模式条件与节点缓存|支持并测试实际显示槽位；切换后重新绑定，停止时恢复|
|格栅/机壳各抖各的|检查父组与轨道成员|共同刚性变换；保持 pivot 和相位一致|
|火焰/闪电脱离部位|观察喷口法向、刃面局部坐标、动作最大姿态|锚定真实出口/表面，检查穿模和厚度|
|旋风分层或俯视不圆|正交俯视区分几何环带与纹理分割|需要连通风面时用目标支持的表示；保持半径约束后再加高度扰动|
|优化后看似一样但比较失败|相机、帧、背景、纹理过滤、alpha、UV 精度分别核对|条件不一致重采；真实差异如实保留，不临时放宽无损标准|

不能凭截图判定作者的精确实现。用倒置壳复现某效果是合理重建方案，不代表已确认原作者用了该技术。

修复结果只写已验证的层级。脚本不报错、BB 预览正常、游戏端实测是不同结果。旧报告若基线已过时，不回滚用户最新动作来迎合旧测试。
