# 几何、上色与贴图

## 拆解与封闭

从识别度最高的轮廓开始：头/身/柄比例，刃尖落点，缺口、镶嵌、分叉和负空间。参考视频还要分离展示相机旋转与武器本体运动。看不见的背面可以推断，但标明推断，不声称来自原图。

一段连续斜边优先尝试旋转部件，曲线只保留影响识别度的转折。粗略的 Minecraft 轮廓与偏精细的 Minecraft 像素风都可成立，遵循用户给定成品的风格，不强制所有圆形都变成单个方块。

- 刃口从厚刀身过渡到薄边，逐段检查前后厚度和接缝。金属饰边/凹槽/白色衬层若有高度差，应有对应的几何层级。
- 单颗镶嵌宝石有一个立体核心和合理镶口，不能在前后各贴一颗冒充贯穿实体；需要对称时以参考为准。
- 旋转矩形仍是矩形，不是任意楔形。薄片用于真正薄的结构及少量装饰；需要立体的部位必须检查侧视封口。透明纹理形成的轮廓要明确识别，不能把它算作真实斜面。
- 对齐共享端点后再考虑小偏移。消除共面竞争优先合并/删去冗余表面；必须叠加的装饰留明确的表面间隔。不要反复堆壳、全局 inflate 或任意扩大所有组件来掩盖穿模。
- 剔除必须依据完整不透明遮挡，考虑旋转、alpha、所有动画姿态；不能仅凭名字、静止截图、未变换 AABB 或“当前不显示”删除。负尺寸壳、薄面、复用 UV 本身都不等于冗余。

## 材质语言

金属用明确的亮边与暗凹槽表达厚度；皮革使用少量成组折痕；木纹跟随杆的方向；冰晶保留清楚的大色块和必要的高亮。几何面的明暗与画出来的表面纹理要配合，避免每个表面都画成中央亮、四周暗。颜色按参考材质本身判断，避免把展示背景、bloom 或预览灯光烘进底色。

新画像素纹理时先确定密度，尽量保持同材质相邻表面的像素大小一致。放大贴图再画更细的像素会造成混合像素密度；全图缩小又无法保留原有独立图案。边缘不整齐优先修像素簇和步进节奏，别自动模糊。无损优化旧图时则保留原有像素、alpha 和采样含义，不套用“禁用所有抗锯齿”的新画规则。

## UV 的三种合理用途

|用途|映射|检查|
|---|---|---|
|纯色金属侧面/阴影面|共用色板中一个小区域；区域内部留余量|确实为纯色、不会采到相邻色、不会误删正反差别|
|木纹、皮革、铆钉等可复用细节|复用/镜像纹理块或连续条带|纹理方向、接缝、可见重复、像素密度|
|独立符文/复杂缺口|紧凑但独立的 UV 岛|图案未裁掉；剪影与立体边缘吻合|

纹理 atlas 的整张宽度不等于每块表面的细节分辨率。JSON UV 通常在 0–16 空间；Blockbench 的 UV 则可能按项目或每张纹理自己的逻辑宽高，不能对全部纹理统一除以 8。

换图集时保留 UV 的方向、旋转、alpha、采样边界和必要 padding。重复区域只有像素内容和采样语义都相同时才能合并。统计已用区域、透明空白、重复颜色和材质批次数；透明面积比例不是准确的 UV 使用率，纯色图也可能浪费大量空间。

动画纹理的每帧尺寸由 `.mcmeta` 等运行数据决定，不靠“长图看起来像动画”判断；32×3072 可以是 96 张 32×32 帧。无损贴图搬移并不保证 GPU 截图逐像素一样，浮点 UV、采样边界及材质绘制顺序都可能影响结果，必须实际对照。
